## Divergence from cz-psp

cz-psp additionally serves `mcp/server-card.json` and `api-catalog` here,
describing a separately deployed "Sněmovna Digest" video-summary
microservice reachable at `/digest`. No such service exists for cz-cities
(there is no digest app for cities), so those files and the `/digest`
rewrite in `next.config.ts` were deliberately **not** copied — see
DIVERGENCE.md in the app root.
