# Authentication — Mesta.DataTimes.cz (placeholder)

## No authentication required

All data on this site is intended to be **publicly accessible**, matching the
rest of the DataTimes/KohoVolit legislature-dashboard family.
No API key, registration, token, or credentials are needed.

## Placeholder scaffold notice

This app (`apps/cz-cities`) is currently a generic, placeholder scaffold

subsystems beyond the pages in this app. Unlike `cz-psp`, there is currently
no separate "digest" microservice or MCP server for cities — this file will
be extended if/when one is built.

## Agent access

published. See `/llms.txt` for a structured site description.

No rate limiting is currently applied. Please be reasonable with request
frequency.
