# Authentication — Mesta.DataTimes.cz

## No authentication required

All data on this site is intended to be **publicly accessible**, matching the
rest of the DataTimes/KohoVolit legislature-dashboard family.
No API key, registration, token, or credentials are needed.

## Coverage notice

This app (`apps/cz-cities`) currently covers the City of Prague (real,
owner-approved data — see the app's DIVERGENCE.md). More cities are added
over time as their data pipelines land. Unlike `cz-psp`, there is no separate
"digest" microservice or MCP server for cities — this file will be extended
if/when one is built.

## Agent access

AI agents may freely crawl, index, and query all content. See `/llms.txt` for
a structured site description.

No rate limiting is currently applied. Please be reasonable with request
frequency.
