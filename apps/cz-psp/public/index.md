# Sněmovna.DataTimes.cz

Dashboard for the Czech Chamber of Deputies 2025-2029 term.

## Main Views

- [MPs](https://snemovna.datatimes.cz/members): sortable table of individual MP metrics.
- [Parliamentary groups](https://snemovna.datatimes.cz/groups): party and club-level aggregate metrics.
- [Regions](https://snemovna.datatimes.cz/regions): regional representation and aggregate metrics.
- [About](https://snemovna.datatimes.cz/about): project context and data source notes.

## Analyses

- Attendance on voting events.
- Rebelliousness against the MP's own parliamentary group.
- Alignment with the governing coalition.
- Vote corrections.
- WPCA voting-position map.
